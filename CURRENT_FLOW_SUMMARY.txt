================================================================================
                    VIBECODE MENTOR: CURRENT USER FLOW
================================================================================

How does it work now? What happens after user generates a blueprint?

================================================================================
                          THE SHORT VERSION
================================================================================

1. User enters project idea (text)
   └─ "Build a REST API with authentication and database"

2. User clicks "Generate Blueprint"
   └─ Frontend calls POST /api/mentor

3. Mistral AI generates blueprint (30 seconds)
   └─ Returns formatted markdown text

4. Blueprint displays nicely
   └─ With buttons: [Copy] [Save] [Export ▼]

5. User sees "Build Full App" button
   └─ If FREE:  Shows "Upgrade to Pro" modal
   └─ If PRO:   Redirects to /build-full-app for code generation

6. That's it for free users
   └─ They either download markdown or upgrade

7. For pro users:
   └─ Full app code is generated and pushed to GitHub

STEP 4: The Critical Decision Point
──────────────────────────────────────────────────────────────────

User clicks "Build Full App" button
  ↓
BuildFullAppButton.tsx executes:
  ├─ Check: isPro = SELECT is_pro FROM users WHERE id = ?
  │
  ├─ If NOT Pro:
  │  ├─ Save blueprint to sessionStorage
  │  │  └─ { projectIdea, blueprint, timestamp }
  │  ├─ Open ProUpgradeModal
  │  └─ User sees:
  │     ├─ Monthly: $5/month
  │     └─ Annual: $50/year
  │
  └─ If IS Pro:
     ├─ Save blueprint to sessionStorage
     ├─ Redirect to /build-full-app
     └─ Code generation starts automatically

STEP 5A: Free User Path (Needs to Upgrade)
──────────────────────────────────────────────
ProUpgradeModal opens:
  ├─ "Upgrade to VibeCode Mentor Pro"
  ├─ Features listed
  ├─ Pricing shown ($5/mo or $50/yr)
  └─ [Upgrade Button]

User clicks "Upgrade"
  ↓
Lemonsqueezy Payment Gateway:
  ├─ Collects email
  ├─ Collects card details
  ├─ Processes payment
  └─ Sends webhook: order_completed

Backend webhook handler:
  ├─ Verify HMAC signature
  ├─ UPDATE users SET is_pro = true WHERE id = ?
  ├─ Send confirmation email
  └─ Return 200 OK

Browser redirects to /payment/success:
  ├─ Shows "✓ Welcome to VibeCode Mentor Pro!"
  ├─ Lists Pro features
  ├─ Shows 5-second countdown
  └─ Redirects to /dashboard

User now has Pro status but:
  └─ Must click "Build Full App" again to trigger code generation

STEP 5B: Pro User Path (Direct to Code Generation)
──────────────────────────────────────────────────
User clicks "Build Full App"
  ↓
BuildFullAppButton detects: isPro = true
  ↓
Immediately redirects to /build-full-app
  ↓
/build-full-app page:
  ├─ Loads blueprint from sessionStorage
  ├─ Initiates code generation
  │
  └─ Shows progress:
     ├─ Step 1: Parsing blueprint structure (5 sec)
     ├─ Step 2: Generating code files (20 sec)
     └─ Step 3: Creating GitHub repository (10 sec)
  ↓
Final page shows:
  ├─ ✅ Code generation complete
  ├─ GitHub repository link
  ├─ "Clone and start building" button
  ├─ Download code as ZIP
  └─ Next deployment steps

                       CURRENT RATE LIMITING
================================================================================

Checked on every blueprint generation:

For FREE users:
  SELECT COUNT(*) FROM blueprints 
  WHERE user_id = ? 
  AND created_at > NOW() - INTERVAL '1 day'
  
  If count >= 3:
    └─ Return 429 Too Many Requests
    └─ Show: "Rate limit exceeded. Upgrade to Pro for unlimited!"

For PRO users:
  └─ No limit, generation allowed

When blueprint is generated:

  2. SELECT COUNT(*) FROM blueprints (rate limit check)

When user saves locally:
  localStorage.setItem('blueprint_' + timestamp, JSON.stringify({...}))

When user saves to cloud:
  INSERT INTO user_blueprints (user_id, blueprint_id, saved_at)

When checking pro status:
  SELECT is_pro FROM users WHERE id = ?

When payment completes:
  UPDATE users SET is_pro = true WHERE id = ?

================================================================================
                     PROBLEMS WITH CURRENT SYSTEM
================================================================================

1. No Project Tracking
   └─ Blueprint is just a text document, no ongoing project management

2. No Team Features
   └─ Completely single-user, can't collaborate with teammates

3. No Community
   └─ Can't share projects or learn from other developers

4. No Code Reuse
   └─ Each blueprint is isolated, can't reuse snippets/components

5. Low Stickiness
   └─ Users generate blueprint once and leave

6. One-time Transaction
   └─ Limited recurring engagement and revenue

7. No Network Effects
   └─ Users are isolated, no incentive to stay

================================================================================
                      THE HUB TRANSFORMATION FIXES THIS
================================================================================

Current:  Blueprint Generator (One-time use)
          └─ User generates, downloads, leaves

Future:   Project Hub (Recurring platform)
          ├─ Generate blueprint
          ├─ Create project
          ├─ Track progress
          ├─ Invite team
          ├─ Share snippets
          ├─ Join community
          ├─ Generate code
          └─ Deploy app
             ↓ (Next project)
             └─ Repeat cycle

From single-transaction to recurring engagement.

SUMMARY:

After a user generates a blueprint:
1. If FREE → They can view, copy, download as markdown
2. If FREE + click "Build" → They must upgrade ($5/month)
3. If PRO → They get full app code generated automatically

Currently it's a simple 2-tier SaaS model:
  - Free: Blueprint generator only
  - Pro: Blueprint + Full app code generation

The Hub transformation adds:
  - Project management
  - Team collaboration
  - Community features
  - Analytics & insights
  - Code snippet library
  - Template marketplace

Making it a sticky, recurring platform instead of a one-time tool.
